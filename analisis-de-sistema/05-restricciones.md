# Restricciones

* **RC01 (Aplicación Web):** Debe desarrollarse como una aplicación accesible mediante un navegador web[cite: 1].
* **RC02 (Control de versiones):** El código debe gestionarse utilizando Git y GitHub en un repositorio compartido[cite: 1].
* **RC03 (API REST):** La comunicación entre frontend y backend debe realizarse mediante una API REST[cite: 1].
* **RC04 (Pasarela de Pago):** Debe integrarse con una pasarela de pago externa para procesar pagos[cite: 1].
* **RC05 (Servicio de Envío):** Debe integrarse con un servicio externo de envío para gestionar las entregas[cite: 1].
