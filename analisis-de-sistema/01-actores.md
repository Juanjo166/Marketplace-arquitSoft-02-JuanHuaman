# Actores del Sistema

| Actor | Tipo | Descripción / Necesidad |
| :--- | :--- | :--- |
| **Cliente** | Humano | Buscar productos, agregar al carrito, pagar y consultar pedidos. |
| **Seller** | Humano | Registrar, actualizar y gestionar productos y ventas. |
| **Administrador** | Humano | Administrar y supervisar la plataforma. |
| **Pasarela de pago** | Sistema Externo | Procesar las operaciones de pago. |
| **Servicio de envío** | Sistema Externo | Gestionar la información de entrega. |
| **Servicio de Facturación** | Sistema Externo | Generar comprobantes de pago. |
| **ERP** | Sistema Externo | Proporcionar información de productos y stock. |
