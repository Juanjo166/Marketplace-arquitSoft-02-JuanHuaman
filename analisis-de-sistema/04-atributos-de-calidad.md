# Atributos de Calidad

* **AC01 (Rendimiento):** Las consultas de productos y operaciones del carrito deben responder rápidamente incluso con alta concurrencia de usuarios[cite: 1].
* **AC02 (Disponibilidad):** El sistema debe permanecer disponible durante campañas comerciales para permitir las operaciones[cite: 1].
* **AC03 (Escalabilidad):** El sistema debe soportar un incremento de usuarios y solicitudes sin afectar su funcionamiento[cite: 1].
* **AC04 (Seguridad):** Los datos de los usuarios, cuentas y operaciones de compra deben estar protegidos frente a accesos no autorizados[cite: 1].
* **AC05 (Mantenibilidad):** El sistema debe estar organizado para permitir cambios y correcciones sin afectar otras funcionalidades[cite: 1].
