# Historias de Usuario

* **HU01:** Como **cliente**, quiero **buscar y consultar productos**, para **encontrar el producto que necesito**[cite: 1].
* **HU02:** Como **seller**, quiero **registrar y gestionar mis productos**, para **ofrecerlos a los clientes**[cite: 1].
* **HU03:** Como **cliente**, quiero **gestionar los productos de mi carrito**, para **preparar los productos que deseo comprar**[cite: 1].
* **HU04:** Como **cliente**, quiero **realizar un pedido con los productos de mi carrito**, para **completar mi compra**[cite: 1].
* **HU05:** Como **administrador**, quiero **gestionar los sellers de la plataforma**, para **administrar a los vendedores registrados**[cite: 1].
* **HU06:** Como **cliente**, quiero **consultar mis pedidos y su estado**, para **conocer el estado de mis compras**[cite: 1].
