# Enfoque Arquitectónico

## Clean Architecture

El sistema adopta el enfoque de **Clean Architecture**, separando las responsabilidades en las capas de Presentación, Aplicación, Dominio e Infraestructura.

El objetivo principal es mantener las reglas de negocio independientes de tecnologías externas como Angular, APIs, bases de datos o servicios de terceros.
